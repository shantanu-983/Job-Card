# 💼 Job Card Management System

A web application built with **React and Vite** to provide a clean and user-friendly interface for job card management.

## 📌 About the Project

The **Job Card Management System** is a web-based project designed to organize job card-related tasks and information.

Built using React and Vite, this project provides a foundation for developing a modern and maintainable web application.

## ✨ Features

- 🎨 Clean and user-friendly interface
- ⚛️ Component-based UI using React
- ⚡ Fast development with Vite
- 🛠️ Maintainable project structure
- 🚀 Foundation for future enhancements

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Building the user interface |
| Vite | Development server and build tool |
| JavaScript | Application logic |
| HTML5 | Page structure |
| CSS3 | Styling and layout |
| ESLint | Code quality and linting |

## 📂 Project Structure

```text
job-card/
├── public/              # Static assets such as images and icons
├── src/                 # Main React application source code
│   ├── App.jsx          # Main React component and UI
│   ├── App.css          # Component styling
│   ├── index.css        # Global styles
│   └── main.jsx         # React entry point
├── index.html           # Main HTML document
├── package.json         # Project configuration and dependencies
├── package-lock.json    # Locked npm dependency versions
└── README.md            # Project documentation
```

### 📄 File Descriptions

- **`public/`** — Stores static assets such as images and icons.
- **`src/`** — Contains the React application source code.
- **`App.jsx`** — Defines the main application component.
- **`App.css`** — Contains component-specific styles.
- **`index.css`** — Contains global CSS styles.
- **`main.jsx`** — Initializes React and renders the application.
- **`index.html`** — Provides the main HTML document.
- **`package.json`** — Defines project metadata, dependencies, and npm scripts.
- **`package-lock.json`** — Records the resolved npm dependency tree.
- **`README.md`** — Documents the project and its setup.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/shantanu-983/job-card.git
```

### 2. Navigate to the Project Directory

```bash
cd job-card
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal. It is usually:

`http://localhost:5173/`

## 📜 Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds the application for production |
| `npm run preview` | Previews the production build |
| `npm run lint` | Runs ESLint checks |
